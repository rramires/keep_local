# Tests

No npm packages are required. Node 24 (native WebSocket and Web Crypto) and Chromium are used.

```
node --test tests/unit
CHROME_BIN=/path/to/chromium node tests/browser/run.mjs
bash build-extension.sh
```

The browser runner binds only to 127.0.0.1 and creates disposable browser contexts/profiles with fictitious data. Missing Chromium is reported as SKIP and does not satisfy browser acceptance. Set KL_BASE_ROOT to a directory produced by `git archive 571fcb7` when generating the v1 fixtures for the first time. Fixtures are encrypted exports generated by the original application and contain only the published fictitious test password.

Legacy imports are limited to 64 MiB per file, 10,000 notes and 2 MiB per
serialized UTF-8 note. All records must authenticate and match their outer IDs
and timestamps before the atomic replacement. V1 cannot detect removal of an
entire record; authenticated v2 backups address this limitation.
