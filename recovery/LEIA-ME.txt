KeepLocal — Kit de emergência
=============================

Guarde num pen-drive criptografado as cópias .keeplocal mais recentes
(arquivo da pasta do cofre, subpasta keeplocal-history/ e backups manuais),
o ZIP da versão em uso, keeplocal-recovery.html, este LEIA-ME.txt e
SHA256SUMS. Guarde a senha mestra separadamente do pen-drive.

1. Ver uma cópia
   Dê duplo clique em keeplocal-recovery.html para abrir no Chrome.
   Escolha o .keeplocal mais recente, digite a senha daquela cópia e
   clique em Abrir. O leitor também abre qualquer cópia de keeplocal-history/.
   A ferramenta só lê o arquivo e permite ler as notas e revelar ou
   copiar um campo por vez. O histórico da área de
   transferência (Win+V) pode reter valores copiados.
   Se a abertura falhar, tente a senha anterior. A cópia pode ter sido
   criada antes da troca de senha.

   Para recuperar pelas fotos, abra as sete fotos dedicadas, uma por vez,
   com a senha de cada cópia. Confira a revisão e a data exibidas. Use a foto
   com a maior revisão (rev) que abriu. Se o leitor indicar que a foto não
   tem uma cópia do cofre, passe para a próxima. No app, escolha essa foto em
   Importar backup para restaurar as notas.

2. Reinstalar o app
   Descompacte o ZIP numa pasta local. Abra chrome://extensions, ative
   Modo do desenvolvedor e clique em Carregar sem compactação. Escolha
   a pasta descompactada que contém manifest.json.
   O ID fixo da extensão é dplgmdpgehkbgphaimafofojbjhlkphm

   Se o Python estiver instalado, abra um terminal na pasta
   descompactada e execute este comando.
   python3 -m http.server --bind 127.0.0.1 8000
   Em seguida, abra http://127.0.0.1:8000 no navegador.

3. Voltar a usar
   Importe o .keeplocal pelo app. Na extensão, também é possível
   escolher a pasta do cofre nas Configurações.

Confira SHA256SUMS usando certutil -hashfile <arquivo> SHA256 no Windows
ou sha256sum -c SHA256SUMS no Linux. Atualize o kit após mudanças
importantes e teste a abertura de uma cópia periodicamente.

KeepLocal — Emergency kit
=========================

Keep the latest .keeplocal copies (vault folder file, keeplocal-history/
subfolder and manual backups), the ZIP for the version in use,
keeplocal-recovery.html, this LEIA-ME.txt and SHA256SUMS on an encrypted
USB drive. Keep the master passphrase separate from the drive.

1. View a copy
   Double-click keeplocal-recovery.html to open it in Chrome. Choose the
   latest .keeplocal file, enter the passphrase for that copy, and click
   Open. The reader also opens any copy from keeplocal-history/.
   The tool reads the file and lets you read notes and reveal or
   copy one field at a time. Clipboard history (Win+V) can retain copies.
   If opening fails, try the previous passphrase. The copy may have been
   created before the passphrase change.

   To recover from photos, open the seven dedicated photos one at a time
   with the passphrase for each copy. Check the displayed revision and date.
   Use the photo with the highest revision (rev) that opens. If a photo
   contains no vault copy, move to the next one. In the app, select the
   chosen photo in Import backup to restore your notes.

2. Reinstall the app
   Unzip the archive to a local folder. Open chrome://extensions, enable
   Developer mode, and select Load unpacked. Select the folder that
   contains manifest.json.
   The fixed extension ID is dplgmdpgehkbgphaimafofojbjhlkphm

   If Python is installed, open a terminal in the unzipped folder
   and run this command.
   python3 -m http.server --bind 127.0.0.1 8000
   Then open http://127.0.0.1:8000 in the browser.

3. Resume use
   Import the .keeplocal file in the app. In the extension, you can
   also choose a vault folder in Settings.

Check SHA256SUMS with certutil -hashfile <file> SHA256 on Windows or
sha256sum -c SHA256SUMS on Linux. Update the kit after important changes
and periodically use the tool to open a backup.
