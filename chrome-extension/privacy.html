📝 KeepLocal

Last updated: November 2026 · Última atualização: Novembro 2026

Summary: KeepLocal stores encrypted notes locally and sends no telemetry. You can explicitly export an encrypted backup or open an external link; the browser or your chosen sync service controls what happens to that file.

1. Data Collection

KeepLocal does not collect any personal data. Specifically:

  • No information is sent to external servers
  • No analytics or tracking is used
  • No cookies are created
  • The notes app makes no remote requests; external links open only on your action

2. Local Storage

Working vault data is stored in your browser's IndexedDB, on your device. Data includes:

  • Notes and tasks (encrypted)
  • Theme preference (dark/light)
  • Cryptographic salt, encrypted key check, language, vault identity and backup metadata

3. Encryption

All note and task data is encrypted using:

  • AES-256-GCM — authenticated symmetric encryption
  • PBKDF2 with 600,000 iterations and SHA-256 for key derivation
  • Random 12-byte IV generated for each encryption operation
  • Web Crypto API native to the browser (no external cryptography libraries)

4. Password

Your password is never stored. An encrypted known block verifies the derived key. The nonextractable session key stays only in memory. Reloading requires your password; inactivity locks after five minutes. New passwords require at least fourteen characters without composition rules. There is no password recovery — if you forget your password, your data cannot be recovered.

Backups use an authenticated binary v2 envelope with an encrypted manifest, revision and parent hash. Export starts a download. KeepLocal cannot confirm that the file was saved. Local preferences and metadata remain unencrypted in IndexedDB.

5. Permissions

KeepLocal declares no Chrome extension permissions. The browser grants access to the folders you choose through the File System Access API. KeepLocal can save encrypted backups and history in your vault folder. Optional dedicated photos can carry an encrypted copy of the vault appended to the image.

When you copy a password or key, KeepLocal writes it to the clipboard and attempts to clear it after 20 seconds. The operating system controls its clipboard history and sharing settings.

6. Open Source

The complete source code is available at github.com/rramires/keep_local under the MIT license. Anyone can audit the code to verify these privacy practices.

7. Contact

For privacy questions, open an issue on the GitHub repository.

Resumo: O KeepLocal armazena notas cifradas localmente e não envia telemetria. Você pode exportar um backup cifrado ou abrir um link externo; o navegador ou seu serviço de sincronização controla o destino desse arquivo.

1. Coleta de Dados

O KeepLocal não coleta nenhum dado pessoal. Especificamente:

  • Nenhuma informação é enviada para servidores externos
  • Nenhum analytics ou rastreamento é utilizado
  • Nenhum cookie é criado
  • O app de notas não faz requisições remotas; links externos abrem por sua ação

2. Armazenamento Local

O cofre de trabalho é armazenado no IndexedDB do seu navegador, no seu dispositivo. Os dados incluem:

  • Notas e tarefas (criptografadas)
  • Preferência de tema (claro/escuro)
  • Salt criptográfico, bloco de verificação cifrado, idioma, identidade do cofre e metadados de backup

3. Criptografia

Todos os dados de notas e tarefas são criptografados usando:

  • AES-256-GCM — criptografia simétrica autenticada
  • PBKDF2 com 600.000 iterações e SHA-256 para derivação de chave
  • IV aleatório de 12 bytes gerado para cada operação de criptografia
  • Web Crypto API nativa do navegador (sem bibliotecas externas de criptografia)

4. Senha

Sua senha não é armazenada. Um bloco conhecido cifrado verifica a chave derivada. A chave de sessão não exportável fica somente em memória. Recarregar exige senha; cinco minutos de inatividade bloqueiam a sessão. Senhas novas exigem quatorze caracteres, sem regras de composição. Não existe recuperação de senha — se você esquecer sua senha, os dados não poderão ser recuperados.

Backups usam envelope binário v2 autenticado com manifesto, revisão e hash do pai cifrados. Exportar inicia um download. O KeepLocal não confirma a gravação. Preferências e metadados locais permanecem sem cifra no IndexedDB.

5. Permissões

O KeepLocal não declara nenhuma permissão de extensão do Chrome. O navegador concede acesso às pastas que você escolhe pela API File System Access. O KeepLocal pode gravar backups cifrados e histórico na pasta do cofre. Fotos dedicadas opcionais podem carregar uma cópia cifrada do cofre anexada à imagem.

Quando você copia uma senha ou chave, o KeepLocal grava na área de transferência e tenta limpá-la após 20 segundos. O sistema operacional controla o histórico e as configurações de compartilhamento da área de transferência.

6. Código Aberto

O código-fonte completo está disponível em github.com/rramires/keep_local sob licença MIT. Qualquer pessoa pode auditar o código para verificar estas práticas de privacidade.
